# Kavita's Beauty Bay — Frontend

> **Live Website:** [https://kavitasbeautybay.com](https://kavitasbeautybay.com)

A modern, responsive frontend web application built for **Kavita's Beauty Bay**, a premier beauty salon located in Swansea and Port Talbot, UK. Designed with a luxury aesthetic, fluid animations, and a mobile-first user experience.

---

## ⚡ Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS v4, Framer Motion
- **Icons & Routing:** Lucide React, React Router DOM v7
- **Code Quality:** ESLint 10

---

## ✨ Key Features

- **Interactive Service & Pricing Menu:** Dynamic treatment showcases and category-based price lists with instant booking triggers.
- **Direct Multi-Channel Booking:** WhatsApp click-to-chat integration, direct telephone calling, and an interactive contact inquiry form.
- **Multi-Branch Location Switcher:** Dynamic Google Maps embeds for 3 salon branches across Swansea and Port Talbot.
- **Loyalty Rewards Showcase:** 3D animated loyalty card presentation with a 10-stamp visual milestone tracker.
- **Media Lightbox & Reviews:** Modal lightbox for parlour photography and video, alongside an automated client review carousel.
- **Verified Credentials:** Interactive showcase of official City & Guilds Level 2 Beauty Therapy certification.

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/anitha-software-dev/kavitas-frontend.git

# 2. Navigate to project directory
cd kavitas-frontend

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` to preview locally.

---

## 📦 Build & Lint
